# CLAUDE.md — project context

This repository holds Sealed Signals, the team's submission to the ACAPS "Ground Truth" challenge at Hackathon for
Good #8 (The Hague, 6–8 November 2026): a working prototype, its tests and design documents. The organisers' original
challenge files are unchanged under `docs/challenge/`, `data/`, `references/` and `notebooks/`.

Where things are:

- `README.md` — what it is, how it works, how to run it, what is real and what is synthetic, what we do not claim.
- `AGENTS.md` — repository map and how to verify each claim.
- `docs/sealed-signals/MASTER_PROMPT.md` — the specification (contracts, routes, algorithms, hardening, UI), with changelog.
- `docs/sealed-signals/trust-design.md` — every mechanism with what it guarantees and what it does not.
- `docs/evidence/` — test output, demo transcript and screenshots.

Working rules: synthetic experts only, no real expert data; no emoji anywhere; commits authored by the team member
who made them; the organisers' files are never edited.
